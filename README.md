# AI Chatbot ออนไลน์ ตอบคำถามจากคู่มือ PDF (มี Login + คลังไฟล์ + สิทธิ์ Admin)

ระบบนี้เป็น **เว็บแอปจริง** เปิดผ่านลิงก์ได้จากทุกเครื่อง ไม่ต้องติดตั้งอะไรที่เครื่องผู้ใช้
ทำครั้งเดียว (deploy) แล้วใช้ได้ตลอด ไม่มีค่าใช้จ่าย (ใช้ free tier ทั้งหมด)

## ภาพรวมระบบ
- **Streamlit Community Cloud** — โฮสต์เว็บแอป (ฟรี)
- **Supabase** — เก็บไฟล์ PDF ต้นฉบับ + ฐานข้อมูลเวกเตอร์สำหรับค้นหา (ฟรี)
- **Google Gemini API** — แปลงข้อความเป็นเวกเตอร์ + สรุปตอบคำถามเป็นไทย (ฟรี)
- **Login**: Admin (จัดการคลังไฟล์ + แชทได้) / User (แชทได้อย่างเดียว)

ทั้งหมดนี้ตั้งค่าครั้งเดียว ใช้เวลาประมาณ 20-30 นาที

---

## ขั้นตอนที่ 1: ตั้งค่า Supabase (เก็บข้อมูล)

1. ไปที่ https://supabase.com สมัครสมาชิกฟรี (ใช้ GitHub login ได้)
2. กด **New Project** ตั้งชื่อ เลือก region ใกล้ไทย (เช่น Singapore) ตั้งรหัสผ่าน database (เก็บไว้ ไม่ต้องใช้ต่อในระบบนี้)
3. รอสร้างโปรเจกต์เสร็จ (1-2 นาที)
4. ไปที่เมนู **SQL Editor** (แถบซ้าย) → New query → เปิดไฟล์ `supabase_setup.sql` ในโปรเจกต์นี้ คัดลอกทั้งหมดไปวาง → กด **Run**
5. ไปที่เมนู **Storage** (แถบซ้าย) → กด **New bucket** → ตั้งชื่อ `pdfs` → เลือก **Private** (ไม่ public) → Create
6. ไปที่เมนู **Project Settings → API** เก็บค่า 2 อย่างไว้:
   - **Project URL** (เช่น `https://xxxxx.supabase.co`)
   - **service_role key** (อยู่ในหัวข้อ Project API keys — เป็น key ลับ อย่าเผยแพร่)

---

## ขั้นตอนที่ 2: ขอ Google Gemini API Key (ฟรี)

1. ไปที่ https://aistudio.google.com/apikey
2. ล็อกอินด้วยบัญชี Google → กด **Create API key**
3. คัดลอก key เก็บไว้

---

## ขั้นตอนที่ 3: อัพโค้ดขึ้น GitHub

1. สร้าง repository ใหม่บน GitHub (private หรือ public ก็ได้) เช่น `pdf-chatbot-online`
2. อัพโหลดไฟล์ทั้งหมดในโปรเจกต์นี้ขึ้นไป **ยกเว้น** โฟลเดอร์/ไฟล์ `.streamlit/secrets.toml` ตัวจริง (มีแค่ `.streamlit/secrets.toml.example` พอ ไฟล์ `.gitignore` กันไว้ให้แล้ว)

ถ้าไม่เคยใช้ GitHub มาก่อน วิธีง่ายที่สุดคือ:
- เข้า https://github.com/new สร้าง repo
- ใช้ปุ่ม **"uploading an existing file"** ในหน้า repo แล้วลากไฟล์ทั้งหมดเข้าไปวาง (ไม่ต้องใช้คำสั่ง git ก็ได้)

---

## ขั้นตอนที่ 4: Deploy บน Streamlit Community Cloud

1. ไปที่ https://share.streamlit.io ล็อกอินด้วยบัญชี GitHub (บัญชีเดียวกับที่อัพโค้ดไว้)
2. กด **New app** → เลือก repository ที่เพิ่งสร้าง → main file path ใส่ `app.py` → กด **Deploy**
3. ระหว่างรอ deploy ให้ไปที่ **App settings → Secrets** วางค่าตามฟอร์แมตนี้ (แก้ค่าตามของจริงที่เก็บไว้จากขั้นตอนที่ 1-2):

```toml
[supabase]
url = "https://xxxxx.supabase.co"
service_key = "eyJxxxxxxxxxxxxxxxxxxxxxx"

[gemini]
api_key = "AIzaSyxxxxxxxxxxxxxxxxxxxx"

[auth]
admin_password = "ตั้งรหัสผ่านของพี่เอง"
user_password = "ตั้งรหัสผ่านของพนักงานทั่วไป"
```

4. กด Save แอปจะ restart อัตโนมัติ รอสักครู่แล้วเปิดลิงก์ที่ได้ (เช่น `https://your-app-name.streamlit.app`) — เอาลิงก์นี้แจกให้พนักงานใช้ได้เลย

---

## วิธีใช้งาน

1. เข้าเว็บ → เลือกบทบาท (admin/user) → ใส่รหัสผ่านที่ตั้งไว้
2. **Admin**: ไปที่เมนู "📚 คลังไฟล์" → อัพโหลด PDF (อัพหลายไฟล์พร้อมกันได้) → กด "เริ่มประมวลผลและเพิ่มเข้าคลัง" รอสักครู่ (ระบบจะอ่าน แบ่งชิ้น แปลงเป็นเวกเตอร์ และบันทึกอัตโนมัติ) กดปุ่ม "ลบ" เพื่อเอาไฟล์ออกจากคลังได้เช่นกัน
3. **ทุกคน**: ไปที่เมนู "💬 แชทถามตอบ" พิมพ์คำถามได้เลย ระบบจะค้นจากไฟล์ทั้งหมดในคลังแล้วตอบเป็นภาษาไทยเสมอ พร้อมบอกแหล่งอ้างอิง

---

## หมายเหตุสำคัญ

- **โควต้าฟรีของ Supabase**: หากไม่มีการเรียกใช้งานนานเกิน 1 สัปดาห์ โปรเจกต์อาจ pause อัตโนมัติ — แค่เข้าไปกด resume ในหน้า dashboard ไม่มีข้อมูลหาย (พื้นที่ฟรี 500MB database + 1GB storage เพียงพอสำหรับคู่มือหลักร้อยหน้าสบายๆ)
- **โควต้าฟรีของ Gemini**: มีจำกัดจำนวนครั้ง/นาทีและ/วัน เพียงพอสำหรับใช้งานภายในทีมเล็กๆ ถ้าคนใช้เยอะมากในอนาคตค่อยพิจารณาอัพเกรดเป็น pay-as-you-go (ราคาถูกมากเมื่อเทียบกับปริมาณการใช้จริง)
- **แอป sleep**: Streamlit Community Cloud จะพักแอปถ้าไม่มีคนเข้าใช้นานๆ พอมีคนเปิดลิงก์จะปลุกขึ้นมาเองใน 30 วินาที-1 นาที (ข้อมูลไม่หายเพราะเก็บแยกไว้ที่ Supabase)
- **PDF ที่เป็นไฟล์สแกน/รูปภาพ**: ระบบดึงข้อความไม่ได้ ต้องเพิ่มขั้นตอน OCR — บอกได้ถ้าเจอเคสนี้ จะเพิ่มโค้ดส่วนนี้ให้
- **อยากเพิ่มบทบาทมากกว่า Admin/User** หรือ **อยากใช้บัญชีพนักงานแต่ละคน login แยกกัน** (ไม่ใช่รหัสกลาง) บอกได้ ทำเพิ่มได้ภายหลัง
